# Bookable: free booking app for barbers, nail technicians and dog walkers

**Bookable** is a UK booking app for solo businesses that take appointments by message. It gives a barber, nail technician or dog walker **one booking link for their Instagram bio and WhatsApp**, a calendar that stops double-bookings, deposits that cut no-shows, and reminders written and ready to send.

- **Try it free for 7 days:** https://pencil-booking.pencil-booking.workers.dev
- **Read the blog (practical booking advice for one-person businesses):** https://spirestudio.github.io/bookable/blog/
- Then £14.99 a month. No booking fees, no contract.

## What it does

- **One booking link** for Instagram and WhatsApp, so clients pick a time themselves instead of messaging back and forth.
- **Calendar and availability:** weekly hours, days off, blocked times, notice rules, no double-booking (enforced on the server).
- **Deposits** to stop serial cancelling: the owner uses their own payment link or bank details and marks them received; unpaid holds are released automatically.
- **WhatsApp reminders and confirmations** with the message ready to send.
- **Customer accounts:** clients can see and cancel their appointments in one place.
- **Calendar sync** to Apple, Google and Outlook calendars.
- **Security:** two-factor sign-in (authenticator app), strong-password checks, rate limiting, sign out of every device, HSTS.
- **Blog:** a new post on the schedule in `src/site/posts*.mjs`, published automatically.

## How it is built

No front-end framework and no tracking scripts. Plain JavaScript on Cloudflare:

| Part | What |
| --- | --- |
| API | A Cloudflare Worker (`src/worker/index.js`) |
| Data | Cloudflare D1 (SQLite), migrations in `migrations/` |
| Owner app | Vanilla JS single page (`src/app/`) |
| Customer area | `src/client/` |
| Public website and blog | Static pages generated by `build.mjs` from `src/site/` |
| Admin | `src/admin/` (private, behind an access code and optional two-factor) |

## Run it yourself

```bash
npm ci
echo "PEPPER=$(openssl rand -hex 32)" > .dev.vars   # any long random string
npx wrangler d1 migrations apply pencil-db --local
npm run dev                                          # http://localhost:8787
```

Tests (start the dev server first): `node tests/api.test.mjs`, `app`, `clients`, `deposits`, `blocks`, `twofactor`, `security`, `calendar`, `parity`, `directory`.

## Blog and GitHub Pages

`tools/pages-site.mjs` builds the public site and blog for GitHub Pages. It only publishes posts whose release time has passed, and the workflow in `.github/workflows/pages.yml` runs it every hour, so the blog index, sitemap and RSS feed (`/rss.xml`) update themselves.
